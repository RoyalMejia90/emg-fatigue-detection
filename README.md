## Project Overview

This project implements a complete signal processing and machine learning pipeline for quadriceps muscle fatigue detection using surface electromyography (sEMG).

The dataset consists of bilateral rectus femoris EMG recordings acquired during single-leg knee extension exercise performed until failure.

The objective is to detect and classify muscular fatigue states from EMG-derived features under subject-wise validation (Nested LOSO).

The best model is exported as a serialized, reproducible artifact so that new raw EMG signals can be analysed **without retraining** (see [External Signal Inference](#external-signal-inference)).

## Scripts

### preprocessing.py

Purpose: Signal filtering, anonymization, RMS computation. Output: PROCESSED/, FIGURES/

### repetition_detection.py

Purpose: RMS peak detection, repetition identification. Output: repetition_summary.csv

### feature_extraction.py

Purpose: Extraction of 11 features across 3 families.
Features:
- **Time:** RMS, MAV, Variance, Waveform Length
- **Spectral:** MDF, MNF, Peak Frequency, Log FInsm5, Low/High Ratio
- **Nonlinear:** Sample Entropy, Higuchi FD
Output: features.csv

### feature_trajectories.py

Purpose: Generate Figure 2 (Normalized trajectories of RMS, MDF, MNF).

### validation.py

Purpose: Fatigue label generation and LOSO fold preparation.
Outputs: fatigue_dataset.csv, loso_folds.csv

### models.py

Purpose: Training and evaluation using Nested LOSO (Outer: LOSO, Inner: GroupKFold), selection of the best model by macro-F1, and export of that model for inference.
Models: Majority Class, Logistic Regression (RMS+MDF), Logistic Regression (All Base), LDA (All Base), Logistic Regression (Ext), LDA (Ext), SVM (RBF), Random Forest.
Outputs: results_extended.csv, summary_extended.csv, predictions_extended.csv, per_class_best.csv, importance.csv, ablation.csv, run_info.txt. Generates Figures 3, 4, 5, 6.
Model export (MODELS/): best_model_<name>.pkl and best_model_metadata.json. The best model is refit on the entire dataset (all 15 subjects); the exported file does not alter any validation result.

### label_analysis.py

Purpose: Label reliability analysis (Cohen Kappa, threshold shifts, boundary shifts).
Outputs: label_sensitivity.csv, within_set_trends.csv

### patient_summarize.py

Purpose: Generate diagnostic dashboards per recording. Output: FIGURES_PAT_SUMMARIZE/

### predict_raw_signal.py

Purpose: Predict fatigue from a single raw EMG CSV using the exported model, without retraining.
Outputs: <csv name>_predictions.csv, <csv name>_prediction_plot.png

### evaluate_external_signal.py

Purpose: Run the same inference and write a descriptive report for an external signal.
Outputs: RESULTS/EXTERNAL/<csv name>/predictions.csv, report.txt, plot.png

## Machine Learning Results (Extended)

Best Model by Macro-F1:

Logistic Regression (RMS + MDF)

Performance:
- Accuracy: 0.649 ± 0.104
- F1 Macro: 0.605 ± 0.141
- ROC-AUC: 0.811 ± 0.079
- PR-AUC: 0.818 ± 0.096
- Cohen Kappa: 0.296 ± 0.209

Best Model by ROC-AUC:

Logistic Regression (Ext) Tuned

Performance:
- ROC-AUC: 0.848 ± 0.080
- PR-AUC: 0.864 ± 0.076
- F1 Macro: 0.582 ± 0.137

Key Finding: The extended features (Nonlinear/Spectral) improved ROC-AUC and PR-AUC, demonstrating their value for capturing complex fatigue dynamics, but the simpler model (RMS+MDF) remained the best for threshold-dependent metrics (F1).

## Exported Model

`MODELS/` is generated automatically at the end of `python src/models.py`; it is not created by any other script. `models.py` exports the model with the highest mean macro-F1 (currently **Logistic_RMS_MDF**, a standardization + logistic regression pipeline using `rms` and `mdf`) to `MODELS/`.

`best_model_<name>.pkl` is a joblib payload with:

| Key | Content |
|---|---|
| model | Fitted scikit-learn model (refit on all 15 subjects) |
| model_name | Name of the selected model |
| features | Ordered list of input features |
| f1_mean, f1_std, roc_auc_mean | Nested LOSO reference performance |
| train_subjects, train_samples | Subjects and windows used for the final fit |
| best_params | Selected hyperparameters (empty for non-tuned models) |
| sklearn_version | scikit-learn version used for training |
| saved_at | Export timestamp |

`best_model_metadata.json` contains the same information in readable form.

Loading without retraining:

```python
import joblib

payload = joblib.load("MODELS/best_model_Logistic_RMS_MDF.pkl")
model = payload["model"]
features = payload["features"]

pred = model.predict(X[features])   # X: DataFrame with the feature columns
```

Use the same scikit-learn version as in training (see `sklearn_version`); the inference scripts warn if it differs.

## External Signal Inference

> **Prerequisite:** the model used for inference is created by `models.py`. Run `python src/models.py` **first** (it needs `RESULTS/fatigue_dataset.csv`, produced by `validation.py`). Until then `MODELS/` does not exist and the inference scripts cannot run.

Analyse a new raw EMG recording without retraining. The input can be a **single CSV with any file name**: the name is never used to infer anything, only the content.

### Input format

- Required column: `Voltage_mV` (raw signal, mV).
- Optional column: `Relative_Time_s`, used to check the sampling rate. Other columns (e.g. `ADC_Value`) are ignored.
- Expected sampling rate: 1000 Hz. If it deviates by more than 2 %, the signal is resampled with a warning; below 900 Hz the analysis stops with an error.
- The recording must contain several repetitions of the movement.

### Usage

Prediction only:

```bash
python src/predict_raw_signal.py --csv path/to/any_name.csv
```

Prediction + report:

```bash
python src/evaluate_external_signal.py --csv path/to/any_name.csv
```

Optional arguments: `--model` (path to another `.pkl`), `--outdir` (output folder), `--peak-prominence` (override the repetition-detection prominence). By default the model is located through `MODELS/best_model_metadata.json`.

### Inference pipeline

Raw CSV → DC removal, 1 Hz high-pass, 20–450 Hz band-pass, 60 Hz notch → RMS envelope → repetition detection (same parameters as `repetition_detection.py`) → segmentation at midpoints between consecutive peaks → feature extraction (same functions as `feature_extraction.py`, only the features required by the model) → saved model → probability and label per repetition.

### Outputs

`predict_raw_signal.py`: `<csv name>_predictions.csv` and `<csv name>_prediction_plot.png`, next to the input file.

`evaluate_external_signal.py` (in `RESULTS/EXTERNAL/<csv name>/`):
- `predictions.csv`: one row per repetition (timing, features, predicted label, probability of fatigue).
- `report.txt`: model and LOSO reference, signal quality, results, trend of the fatigue probability, quality flags and limitations.
- `plot.png`: (a) RMS envelope with detected repetitions, (b) fatigue probability per repetition with trend, (c) model input features per repetition.

### Limitations

- No ground-truth labels are assumed, so no accuracy/F1/AUC is computed for the new signal.
- The model's reference performance is moderate and variable across subjects (macro-F1 0.605 ± 0.141 under LOSO). The per-repetition probability and its trend are more informative than a single label.
- `rms` is used in absolute units (mV); signals acquired with a different gain or electrode setup than the training data can shift the probabilities regardless of muscle state.
- Repetition detection uses an absolute prominence (10 mV on the RMS envelope). If no peaks are found, a relative threshold is used as a fallback and a warning is reported; check the repetition markers in the plot.
- A trend is only described when at least 5 repetitions are analysed.
- Results describe the sEMG pattern relative to the training population and are not a clinical diagnosis.

- Subject-wise validation (Nested LOSO)
- Random seed = 42
- All paths generated dynamically from project root
